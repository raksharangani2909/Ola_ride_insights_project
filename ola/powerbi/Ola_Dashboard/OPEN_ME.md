# Ola_Dashboard - Power BI Project (.pbip)

5 pages, 54 visuals: Overall, Vehicle Type, Revenue, Cancellation, Ratings (as in the project brief),
16 DAX measures, synced Date / Vehicle / Status slicers, Top-5 filters, custom colour theme.

## Open it and save as .pbix
1. Power BI Desktop > File > Options > Preview features > tick **Power BI Project (.pbip) save option** and **TMDL**. Restart Desktop.
2. Copy `data/ola_rides_clean.csv` to `C:\Ola\ola_rides_clean.csv` (or any path - see step 4).
3. File > Open > Browse > select `Ola_Dashboard.pbip`.
4. If it asks for the file location / shows a data error: Home > Transform data > Manage parameters > set
   **DataFilePath** to your CSV's full path > Close & Apply.
5. Check each page. **File > Save as > .pbix** -> this is your `Ola_Dashboard.pbix`.

## If something looks off
This project was generated by script and checked against Microsoft's published schemas, but not opened in Desktop.
A visual that renders blank can be fixed by re-dragging its fields; formats (titles, colours) are in the Format pane.
If Desktop reports an error opening the project, send me the exact message and I will fix the file.
